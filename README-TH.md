# ใช้งานแบบง่าย: ใส่ URL จุดเดียว

## หากมี Google Script ที่ใช้ Code.gs ฉบับนี้แล้ว
1. เปิด `config.js` ด้วยโปรแกรมแก้ข้อความ
2. แทน `PASTE_YOUR_WEB_APP_URL_HERE` ด้วย Web App URL ที่ลงท้าย `/exec`
3. อัปโหลด **ไฟล์และโฟลเดอร์ในชุดนี้** ไปยังโฮสต์เว็บแบบ Static โดยให้ `index.html` อยู่ที่รากเว็บไซต์ แล้วเปิดเว็บผ่าน HTTPS

ไม่ต้องติดตั้ง Node.js ไม่ต้อง npm install ไม่ต้อง build และไม่ต้องตั้ง environment variables

```js
window.EBOOK_CONFIG = {
  WEB_APP_URL: "https://script.google.com/macros/s/รหัสของคุณ/exec"
};
```

## ตั้ง Google Sheet ครั้งแรก (ครั้งเดียว)
1. สร้าง Google Sheet → ส่วนขยาย (Extensions) → Apps Script
2. ลบโค้ดเดิม แล้ววางโค้ดจาก `google-apps-script/Code.gs` → บันทึก
3. เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์
4. Deploy → New deployment → Web app → Execute as: **Me** → Who has access: **Anyone** → Deploy
5. คัดลอก Web App URL มาใส่ `config.js` ตามด้านบน เสร็จแล้ว

ถ้าใช้สคริปต์จาก ZIP รุ่นก่อน ให้แทนด้วย Code.gs ในชุดนี้และ Deploy เวอร์ชันใหม่ก่อน ใช้ URL ของ Web App ไม่ใช่ URL ของ Google Sheet

## วิธีใช้
- กดเริ่มอ่าน → หนังสือเปิดพร้อมแสงและแอนิเมชัน 3D
- ปุ่มรูปอุ้งเท้าเล็ก ๆ ที่ส่วนท้ายหน้าแรก → PIN `1234` → dashboard
- สถิติเริ่มเก็บเมื่อกดเริ่มอ่าน รวมจำนวนคนเริ่มอ่าน / อ่านจบ / ยังไม่จบ / เวลาแต่ละหน้า / หน้าที่หยุดอ่านบ่อย
- อ่านจบหมายถึงเปิดครบทั้ง 15 หน้าในรอบเดียว คนประมาณจากเบราว์เซอร์ไม่ซ้ำ ไม่ใช่การยืนยันว่าอ่านทุกคำ
- มีชีต Sessions, PageTime และ Dashboard สรุปในชีตอัปเดตทุก 5 นาที และ dashboard เว็บโหลดทุก 30 วินาที
- เน็ตหลุดจะเก็บคิวไว้ในเบราว์เซอร์แล้วลองส่งใหม่ ข้อมูลก่อนปิดเว็บทันทีอาจส่งไม่ทัน
- ไม่มีสารบัญ รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

ไฟล์เว็บพร้อมอัปโหลดอยู่ที่รากชุดนี้ โฟลเดอร์ `source` เป็นซอร์สสำหรับแก้โครงสร้างเว็บภายหลัง ไม่ต้องใช้ในการเปิดเว็บ

การตรวจสอบ: build/typecheck ผ่าน และทดสอบการเชื่อมต่อแบบจำลองทั้ง frontend กับ Apps Script ผ่าน ยังไม่ได้เชื่อมชีตจริงเนื่องจากยังไม่ได้รับ Web App URL ของคุณ
